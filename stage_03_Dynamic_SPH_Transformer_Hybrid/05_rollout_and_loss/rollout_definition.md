# Rollout definition

A rollout segment starts with accepted state `S^0` and up to three preceding reference states solely as H=4 warm-start history. From the rollout origin onward, all accepted states are generated by the selected arm through the frozen RK2 hybrid solver. Reference states are targets for loss/evaluation only and are never injected into intermediate dynamics.

The preregistered controlled horizon ladder is `K=1 -> 2 -> 4 -> 8`. Advancement requires the preceding horizon's frozen qualification gate. Failed horizons and trajectories remain in the record; success at a shorter horizon cannot substitute for longer-horizon qualification. A long autonomous rollout is a later D5 activity, not Stage 03A execution.

Each rollout record must bind trajectory lineage, warm-start hashes, initial state, dt, resolution, support, arm/parameter/normalization hashes, graph/state sequence hashes, horizon, self-feed status, reference class, and first-failure evidence. Stage 03A authorizes no rollout execution.
