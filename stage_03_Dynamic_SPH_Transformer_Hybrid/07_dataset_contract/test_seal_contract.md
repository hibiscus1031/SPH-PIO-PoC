# Test-seal contract

Stage 03 requires a new sealed-test collection with lineage components disjoint from training/validation/independent validation. Stage 02's test is already `consumed_confirmatory_test` and may be cited only as historical evidence; it cannot be relabeled blind, used for Stage 03 normalization, threshold selection, or model selection.

Before training, the seal records component IDs, payload/content hashes, reference qualification, frozen metrics/gates, allowed release trigger, authorized evaluator, and access log. Test targets remain inaccessible until D4 K=1/2/4/8 training and family-isolated validation decisions are irrevocably frozen under Stage 03F.

Opening the seal consumes the test for any later adaptive decision. Failed test families and all failure evidence remain. Independent source-free D-R3/D-R4 is a distinct role and is not merged with the sealed fitting test.
