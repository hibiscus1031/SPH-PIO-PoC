# Publication reproducibility

## Scope

This index describes the current ability to rebuild publication material without modifying frozen scientific evidence. It does not authorize a new training run, sealed-test access, or scientific recomputation.

## Figures

The CMAME figure suite is generated by the Python sources under `publication_cmame_v1/04_figures/`, including `00_style/build_main_figures.py`, `00_style/build_supplementary_figures.py`, per-figure `*_plot.py` scripts, and `00_style/validate_figure_suite.py`. Final export identity is indexed by `publication_cmame_v1/04_figures/14_exports/figure_files_manifest.csv` and `.json`.

Inputs are existing stage reports, manifests, and frozen source-data files. Outputs are the individual figure-module files and `14_exports/`. The export ZIP, render caches, literature full text, and large generated source-data payloads are intentionally outside ordinary Git. Because some required numerical inputs remain external and the environment is not fully locked, the suite is **PARTIAL** rather than universally reproducible from a fresh clone.

No manual change to a plotted scientific value is authorized. Any typography/layout-only manual post-processing must be documented alongside the affected export; none is inferred from file timestamps.

## Tables and manuscript

Publication tables and claim boundaries are sourced from the Stage08Z manuscript source pack, claim matrix, final reports, and the CMAME manuscript tree. Where a table lacks a single executable generator mapping, its status is `MANUAL_OR_PARTIALLY_REPRODUCIBLE`.
