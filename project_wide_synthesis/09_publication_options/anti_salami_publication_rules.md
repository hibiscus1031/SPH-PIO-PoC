# 反切香肠与重复发表规则

1. 同一冻结结果只能在一篇论文中作为主贡献；另一篇仅作带引用的背景。
2. Stage03C zero-correction、Stage03D 360-probe与TE1图表归Paper1；Stage04训练/rollout/refinement/cost归Paper2。
3. 禁止同一图表换色或裁剪后重复；共享方程只保留最小背景并交叉引用。
4. Paper1结论是资格边界和负结果方法；Paper2结论必须由Stage04新证据产生。
5. 两稿同步披露相关稿件、共享数据/代码与前序结果。
6. 若Paper2没有独立问题、独立结果和独立图表包，则合并而非拆分。
