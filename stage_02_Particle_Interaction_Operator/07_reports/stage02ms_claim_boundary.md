# Stage 02M-S — Formal claim boundary

## SUPPORTED CLAIMS

- Claim: 构建了 reference-qualified、lineage-disconnected 的 blind multifamily pair-scope dataset。
  - Allowed: 在冻结 periodic-vortex、20-graph、pair-scope 下构建并资格化了 blind multifamily dataset。
  - Prohibited: 构建了适用于任意流动的大规模 truth dataset。

- Claim: pair-force architectures 强制离散线性动量守恒。
  - Allowed: K1/K2 的互易 pair-force 构造在冻结合同下满足反对称与全局线性动量。
  - Prohibited: 模型因此动态稳定或精确。

- Claim: K1/K2 满足冻结的 O(2)、periodicity、permutation 与 Galilean contracts。
  - Allowed: 在预注册 metamorphic matrix 与 float64 tolerance 下结构门 PASS。
  - Prohibited: 可泛化到任意几何或任意分布。

- Claim: 两个预注册静态拟合协议均未达到 train-fit qualification。
  - Allowed: v0.1 与 v0.2 均按原门槛判为 NOT QUALIFIED。
  - Prohibited: 所有 learned corrections 都不可学习。

- Claim: 架构正确性不蕴含静态可学性。
  - Allowed: 结构硬门 PASS 与两次静态训练资格失败同时成立。
  - Prohibited: 结构合同无价值。

- Claim: 测试封存与一次性释放机制可审计。
  - Allowed: 两轮 protocol 均保留选择闭包与 sealed-test provenance。
  - Prohibited: test PASS 证明模型成功。

## CONDITIONAL CLAIMS

- Claim: optimization conditioning 对 v0.1 failure 有重要贡献。
  - Allowed: 诊断显示 loss scale、epsilon 与 weight decay 共同限制有效更新；这是贡献性归因。
  - Prohibited: 优化条件是唯一根因。

- Claim: v0.2 改善 conditioning 与 transfer gates。
  - Allowed: 相对 v0.1 可描述 conditioning 与 frozen gate pattern 改善。
  - Prohibited: v0.2 在统计上显著优于 v0.1。

- Claim: 当前 local feature-to-coefficient mapping 可能仍难以识别。
  - Allowed: 结合 K1/K2 train-fit seed counts 作为待检验机制。
  - Prohibited: 已证明 feature identifiability 不可能。

## UNSUPPORTED CLAIMS

- Claim: learned correction improves SPH
  - Allowed: 当前没有 solver/rollout性能证据。
  - Prohibited: 学习修正已提高 SPH 精度。

- Claim: learned model restores V2
  - Allowed: Stage 01 仍为 V2_QUALIFICATION_FAIL。
  - Prohibited: 模型恢复了 V2。

- Claim: attention is superior
  - Allowed: K2 无2/3 train-fit，且新旧协议非架构优越性试验。
  - Prohibited: attention 优于 MLP。

- Claim: Transformer is necessary
  - Allowed: 没有 necessity ablation；K2 是 reciprocal attention，不构成 Transformer 必要性。
  - Prohibited: Transformer 是必要条件。

- Claim: rollout is stable
  - Allowed: rollout 未授权、未执行。
  - Prohibited: rollout 稳定/失败。

- Claim: solver is accelerated
  - Allowed: 无 solver-in-loop 或 wall-clock comparison。
  - Prohibited: solver 被加速。

- Claim: arbitrary-flow generalization
  - Allowed: families与物理范围有限。
  - Prohibited: 泛化到任意流动。

- Claim: viscosity operator is confirmed
  - Allowed: Stage 01H 仍为 NOT_CONFIRMED。
  - Prohibited: 黏性算子形式已确认/否定。

- Claim: high-resolution SPH is truth
  - Allowed: reference hierarchy 明确反对按分辨率排序真值。
  - Prohibited: 最高分辨率即 truth。
