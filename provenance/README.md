# Provenance index

This directory connects versioned software state to existing scientific evidence without copying large datasets or rewriting historical claims.

- `repository_state.md`: verifiable migration-time software state.
- `environment/environment_audit.md`: environment-definition audit.
- `datasets/dataset_manifest.csv`: index of existing dataset/evidence manifests; existing manifests remain the source of truth.
- `experiments/experiment_registry.csv`: stage-level code/evidence linkage.
- `releases/`: future verified release records.
