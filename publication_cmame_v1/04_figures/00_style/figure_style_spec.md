# CMAME figure style specification — v1

## Scope and evidence rule

This style is for the frozen qualification-first neural-SPH evidence suite.  SVG and
PDF are the primary line-art deliverables; 600 dpi PNG files are review previews.
Plotting may read only frozen JSON, JSONL, CSV, NPZ, reports, and manifests.  Sorting,
unit conversion, axis transforms, bin assignment, and layout coordinates are display
transformations, not new scientific results.  No solver, model, optimizer, training,
simulation, candidate generation, threshold fitting, or sealed-test evaluation is
permitted.

The final canvas is 190 mm wide (Elsevier full-page artwork width) with a figure-specific
height.  Text remains editable in SVG and TrueType-embedded in PDF.  Captions are stored
beside, rather than embedded below, the figure.

Official technical references consulted for export policy:

- https://www.elsevier.com/about/policies-and-standards/author/artwork-and-media-instructions
- https://www.elsevier.com/en-gb/about/policies-and-standards/author/artwork-and-media-instructions/artwork-types
- https://www.elsevier.com/en-au/about/policies-and-standards/author/artwork-and-media-instructions/artwork-sizing

## Typography

| Role | Size | Weight |
|---|---:|---|
| Panel label | 10 pt | bold |
| Figure title used in review preview | 9.5 pt | bold |
| Panel title | 8.5 pt | semibold/bold |
| Axis label | 8.0 pt | regular |
| Tick/legend/body | 7.2–7.6 pt | regular |
| Provenance tag | 6.2 pt | regular |

Font stack: Arial, Helvetica, DejaVu Sans, Liberation Sans.  Math uses matplotlib's
mathtext with upright descriptive subscripts where appropriate.  Stage identifiers are
small provenance tags and never the primary visual storyline.

## Geometry

- Full width: 190 mm (7.4803 in).
- Main figures: normally 150–225 mm high, chosen by panel count.
- Graphical abstract: 190 × 95 mm.
- Outer margin: at least 3 mm; panel gutter: 2.5–5 mm.
- Axes: left and bottom spines only, 0.65 pt; ticks 0.6 pt.
- Data lines: 1.1–1.6 pt; threshold/reference lines: 0.9 pt.
- Markers: 3.5–5.0 pt; scatter edges: 0.45–0.6 pt.
- Panel labels: lowercase bold `a`, `b`, … at the top-left.

## Palette and redundant encoding

The palette is based on the colorblind-safe Okabe–Ito family.  Every status or dataset
role also has a marker, line style, outline, or hatch so that grayscale remains legible.

| Identity | Color | Redundant encoding |
|---|---|---|
| D0 | `#4D4D4D` | circle, solid, light gray fill |
| D1 | `#0072B2` | circle, solid |
| D2 | `#009E73` | square, dashed |
| D3 | `#CC79A7` | diamond, dash-dot |
| TRAIN | `#2B4C7E` | solid |
| VALIDATION | `#E69F00` | dashed |
| SEALED | `#111111` | locked/hatched placeholder only; never evaluated or plotted as performance |
| VERIFIED | `#0072B2` | circle/check, solid outline |
| QUALIFIED | `#009E73` | square/check, double outline |
| NOT QUALIFIED | `#D55E00` | cross, dashed outline, `////` hatch |
| DIAGNOSTIC | `#E69F00` | triangle, dotted outline, `..` hatch |
| NOT ACCESSED | `#6B6B6B` | lock, blank/gray hatch |

Green/red alone is never used as the only PASS/FAIL distinction.  Thresholds use a dark
dashed line plus a direct label.  Failed runs, seeds, coordinates, and gates remain
visible; they are never dropped for visual cleanliness.

## Axes, legends, and notation

- White background; no seaborn and no rainbow colormaps.
- Sparse light-gray major guides are allowed only when they materially aid comparison.
- Legends are frameless and shared when possible; stable identities use direct labels.
- Related panels use the same limits when a visual comparison is intended.
- Log axes are explicitly labelled.  Symlog is used only for signed, multi-decade data.
- `Q_train`, `Q_val`, `L_def`, `s_a`, `u_a`, `a_cons`, `a_cm`, and `Delta v` are used
  consistently across figures.
- PASS/FAIL words are always accompanied by the redundant visual grammar above.

## Data-role grammar

- TRAIN: solid navy line or navy fill.
- VALIDATION: orange dashed line with square markers.
- SEALED: lock-only governance symbol.  No decoded value, curve, score, or inferred
  performance is shown.
- Diagnostic evidence: amber/dotted and explicitly labelled `DIAGNOSTIC`.
- Confirmatory evidence: blue/green solid and labelled `VERIFIED` or `QUALIFIED`.
- Frozen negative verdicts: vermillion dashed/cross-hatched and labelled
  `NOT QUALIFIED`.

## Export contract

Each figure directory contains:

- editable `*.svg`;
- font-embedded `*.pdf`;
- `*.png` at 600 dpi;
- `*_source_data.json` and, where tabular, `*_source_data.csv`;
- `*_plot.py`;
- `caption.md`, `panel_spec.md`, and `evidence_map.json`.

SVG must retain `<text>` elements (`svg.fonttype = none`).  PDF uses TrueType font type
42.  All output is generated by Python/matplotlib.  Raster screenshots and manual data
point editing are prohibited.

## Review-risk controls

- Never imply Transformer superiority, general failure of neural SPH, successful
  training, successful validation, sealed-test performance, V2 qualification, GCI,
  high-resolution truth, or target truth.
- D3 validation behaviour is shown as observed frozen evidence, not superiority.
- Coordinate-level FD misses remain visible beside actual optimizer-path qualification.
- Descriptor-space support and target-manifold support use different encodings and are
  never collapsed into one pass indicator.
- Conceptual schematics are labelled as such and trace to frozen method contracts.
