# Stage 01F5 主配置冻结

## 几何与时间参数

主配置同时用于 MMS-A 与 MMS-B：`N=20`，粒子数 400，`dx=0.1`，`t_final=0.015`。

支持半径比冻结为

\[
H/\Delta x=\frac{\sqrt{18}+\sqrt{20}}{2}=4.357388321059432,
\]

因此 `H=0.4357388321059432`。最近下壳层为 `sqrt(18)`，最近上壳层为 `sqrt(20)`；上下 margin 分别为 `0.11474763394014698` 和 `0.11474763394014786`。

时间步固定为 `1e-3, 5e-4, 2.5e-4, 1.25e-4, 6.25e-5`。共同时间固定为从 `0.000` 到 `0.015`、间隔 `0.001` 的 16 个时刻。任何共同时间都不得由插值生成。

## 静态 novelty audit

Stage 01F3B 主配置不是 N20；Stage 01F3C 主配置和 held-out 也不是 N20。对既有实验、报告、JSON/YAML/Python 配置与记录的静态检索未发现相同 N20/`H/dx` 配置。即使未来发现参数局部相似的旧记录，任何旧轨迹也不得计入本次资格。

## 不可变性

执行阶段不得改变 N、粒子数、`dx`、`H/dx`、H、壳层 margin、`t_final`、五级 `dt` 或 16 个共同时间。每个未来 run ID 必须使用独立子进程和独立输出目录。
